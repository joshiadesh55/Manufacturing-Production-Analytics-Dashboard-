# Manufacturing-Production-Analytics-Dashboard-
Manufacturing Production Analytics Dashboard built in Power BI with interactive KPI cards, production insights, revenue analysis, defect tracking, plant performance, and dynamic filtering using DAX and Power Query.
his Power BI project provides an interactive dashboard for monitoring manufacturing performance and production efficiency. It helps analyze revenue, production, profitability, quality, and plant performance through dynamic visualizations and KPIs.

**Key Features**
   Interactive KPI Cards
   Revenue Analysis by Plant
   Production Analysis by Plant
   Top 7 Products by Production
   Monthly Production Trend
   Defect Analysis by Category
   Revenue vs Cost Comparison
   Dynamic Filters and Slicers
   Bookmark Navigation
   Responsive Dashboard Design
**Tools & Technologies**
   Power BI
   Power Query
   DAX
   Excel
   Data Modeling
**KPIs**
   Total Revenue
   Total Production
   Total Plants
   Total Employees
   Profit Margin
   Achievement %
   Defect Rate
   Total Profit
